# Русификатор Super Robot Wars V (PC/Steam)

Полный русский перевод игры: интерфейс, сюжет, боевые реплики, энциклопедия,
заставки, шрифт. Работа идёт порциями — см. [ROADMAP.md](ROADMAP.md) с деревом
прогресса и [ARCHIVES.md](ARCHIVES.md) с картой всех архивов игры.

### ⚠️ Известная проблема: KPACK_P4_RG_EN.CPK

С переведёнными системными сообщениями игра падает на старте (exit −1).
Исключено: сборка (identity-пересборка байт-в-байт работает), кириллица как
таковая и изменение длины строк (точечные тесты запускаются). Падение вызывают
какие-то конкретные записи; бисекция сузила круг до записей 0–26. Перевод
сохранён в `translations/system/KPACK_RG_RU.json`, установка отложена.
Сводки миссий (`KPACK_P4_LN`) из того же пака тоже пока не ставим.

## Установка

Нужен Python 3.x и pycryptodome (`pip install pycryptodome`).

```powershell
.\build.ps1 -GameDir "D:\games\SUPER ROBOT WARS V"
```

Скрипт собирает патченные CPK из файлов игры и JSON-переводов, делает бэкапы
оригиналов (`*.cpk.bak`) и устанавливает. Откат:

```powershell
.\build.ps1 -GameDir "..." -Restore
```

Игра при установке должна быть закрыта — иначе файлы заблокированы.

## Как это устроено

Текст лежит в CPK-архивах (CRI Middleware), внутри — файлы, шифрованные
Blowfish ECB big-endian (ключ `SRVW Steam Game`). Дальше начинается
разнообразие: у каждой подсистемы свой формат, и под каждый написан парсер
с гарантией побайтовой пересборки.

| Формат | Где | Что внутри |
|---|---|---|
| **BLTU** | SysText, LT00 | таблица «ключ → строки» |
| **Lua** | STGEST | сценарии миссий, реплики `[[Имя\n「Текст」]]` |
| **свой** | Prologue | заставки: записи `text[F] + meta[30]` |
| **секции** | CMN00 | боевые субтитры: `count + offsets + пул строк` |
| **ZKAN** | MtZkn_* | энциклопедия; обфускация — условный XOR 0x5E |
| **MTFL** | MtV_all_keyword_def | статьи справки; текст под XOR 0x7A |
| **`<mt>`** | rpw_jstr, lega_zkn | имена юнитов, словарь терминов |

**Общие**

| Скрипт | Назначение |

файлы по 0x800, а игра читает ITOC-архивы последовательно с `Align=16` —
архив получается битым.

### Шрифт

Кириллица в атласе игры есть, но метрики у неё были полноширинные
(advance = 41 px, как у иероглифов) — текст выглядел р а з р е ж е н н ы м.
Формат метрик (файл id=3 в `FontInfo.cpk`, после расшифровки): заголовок
40 байт, затем записи по 36 байт — `uint32 codepoint` + 8 × float32:
`u, v, w, h` (прямоугольник в атласе 4096×4096), `left_bearing`, `advance`,
`const`, `ink_width`; сортировка по codepoint по убыванию. Фикс:
`left_bearing = 2`, `advance = ink_width + 4` (по образцу латиницы).

## Правка перевода

Все переводы — в `translations/`:

| Файл / каталог | Что |
|---|---|
| `SysText_RU.json`, `LT00_RU.json` | интерфейс и база юнитов |
| `dialogs/` | сюжет по файлам (`NNNNNNNN.json`) + глоссарий имён `_speakers_ru.json` (385 персонажей) |
| `battle/cmn_tm.json` | память переводов боевых реплик (EN → RU) |
| `battle/cmn_block_map.json` | карта блоков реплик по персонажам и сериям |
| `encyclopedia/` | статьи ZKAN + индекс всех 684 записей |
| `keywords/` | статьи справки KeyWord |
| `prologue/`, `system/` | заставки, сводки, системные сообщения |

Отредактировать строку → пересобрать соответствующий CPK. Ограничения:
число строк в записи менять нельзя, сохранять управляющие коды (`\c0`/`\c1`),
плейсхолдеры (`%s`, `%d`, `$n`, `$kwb…$kwe`, `$l/$c/$r/$F`), японские скобки
`「」（）` и отступы U+3000. Длина строки — не больше оригинала (+10 % для UI,
+50 % для боевых выкриков), иначе текст вылезет за рамку.

Единая терминология (правится в `TRANSLATE_RULES.md`): Воля (Focus), Умения
(Spirit Commands), Действие-Экс / Приказ-Экс, ньютайп, мобильный доспех,
волновая пушка, «Ямато», «Вангрэй», Кроссбоун-Вангард, Империя Юпитера,
частицы Миновского, Чар, «Кьюбелей», «Гаранциер».
