# Русификатор Super Robot Wars V (PC/Steam)

Перевод интерфейса и базы юнитов + исправление метрик кириллицы в шрифте игры.

### ⚠️ Известная проблема: KPACK_P4_RG_EN.CPK

С переведёнными системными сообщениями игра падает на старте (exit −1).
Исключено: сборка (identity-пересборка байт-в-байт работает), кириллица как
таковая и изменение длины строк (точечные тесты запускаются). Падение вызывают
какие-то конкретные записи перевода; бисекция сузила круг до записей 0–26.
Перевод сохранён в `translations/system/KPACK_RG_RU.json`, установка отложена.
Сводки миссий (KPACK_P4_LN) из того же подсистемного пака тоже не ставим,
пока причина не найдена.

## Установка

Нужен Python 3.x и pycryptodome (`pip install pycryptodome`).

```powershell
.\build.ps1 -GameDir "D:\games\SUPER ROBOT WARS V"
```

Скрипт собирает три патченных CPK из файлов игры + JSON-переводов, делает
бэкапы оригиналов (`*.cpk.bak`) и устанавливает. Откат:

```powershell
.\build.ps1 -GameDir "..." -Restore
```

## Как это устроено

Текст игры лежит в CPK-архивах (CRI Middleware, чисто ITOC — без имён файлов),
внутри — файлы, шифрованные Blowfish ECB big-endian (ключ `SRVW Steam Game`),
тексты — в формате BLTU (бинарная таблица ключ → строки, UTF-8).

Пайплайн: `cpk_extract.py` → `srwv_decrypt.py` → `bltu_parser.py extract` →
перевод JSON → `bltu_parser.py rebuild` → `srwv_encrypt.py` → `ru_cpk_patch.py`.

### Инструменты (`tools/`)

| Скрипт | Назначение |
|---|---|
| `cpk_extract.py` | Распаковка CPK (TOC и ITOC, CRILAYLA-декомпрессия) |
| `srwv_decrypt.py` / `srwv_encrypt.py` | Blowfish-шифрование файлов игры |
| `bltu_parser.py` | BLTU ↔ JSON (extract / rebuild) |
| `ru_cpk_patch.py` | Замена файла в ITOC-CPK по ID: правит размеры прямо в XOR-шифрованных @UTF-таблицах, раскладка с Align=16 от ContentOffset |
| `ru_font_metrics.py` | Фикс метрик кириллицы в таблице пропорционального шрифта (FontInfo, файл id=3) |
| `ru_split.py` / `ru_merge.py` | Нарезка JSON для перевода по частям и сборка с валидацией (ключи, `\c`-коды, `%s/%d`, число строк) |
| `ru_lua_dialog.py` | Извлечение/вставка диалоговых блоков `[[Имя\n「Текст」]]` в Lua-скриптах стадий |
| `ru_stage_build.py` | Сборка STGEST: валидация переводов → инжект → шифрование → мультизамена в CPK |

⚠️ CriPakTools/CriPakGUI для запаковки этих архивов непригодны: они
выравнивают файлы по 0x800, а игра читает ITOC-архивы последовательно
с выравниванием `Align=16` — архив получается битым.

### Шрифт

Кириллица в атласе игры есть, но метрики у неё были полноширинные
(advance = 41 px, как у иероглифов) — текст выглядел р а з р е ж е н н ы м.
Формат метрик (файл id=3 в `FontInfo.cpk`, после Blowfish-расшифровки):
заголовок 40 байт, затем записи по 36 байт — `uint32 codepoint` +
8 × float32: `u, v, w, h` (прямоугольник в атласе 4096×4096),
`left_bearing`, `advance`, `const`, `ink_width`; сортировка по codepoint
по убыванию. Фикс: `left_bearing = 2`, `advance = ink_width + 4`
(по образцу латинских глифов).

### Правка перевода

Переводы — `translations/SysText_RU.json` и `translations/LT00_RU.json`
(рядом — английские оригиналы). Отредактировать строку → `.\build.ps1 ...`.
Ограничения: число строк в `values` каждой записи менять нельзя, коды
`\c0`/`\c1`, `%s`/`%d` и ссылки на ключи (`CAPS_WITH_UNDERSCORES`) сохранять.

### Диалоги сюжета

`translations/dialogs/` — переводы по файлам CPK (`NNNNNNNN.json`),
глоссарий имён говорящих (`_speakers_ru.json`, все 385), карта
id → имя стадии (`_stage_map.json`). Правила блоков: поля `i`/`orig`
не менять, реплика `「…」`, строки-продолжения с U+3000, плейсхолдеры
`$n`, `$kwb…$kwe`, `$l/$c/$r/$F` сохранять. Сборка (из каталога игры
с `_extracted/`): `python tools/ru_stage_build.py <game_dir> <out.cpk> 3 4 9 10`.
Дубли между рутами (~31%) переводятся один раз через память переводов.
