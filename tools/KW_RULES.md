# Правила перевода статей справки KeyWord (EN → RU)

Это окно «KeyWord» в игре: справка по терминам вселенных кроссовера —
события, организации, технологии, места. Открывается по подсвеченному
термину в диалоге.

## Порядок работы

Длинные ответы обрываются, поэтому строго по одному файлу за раз: прочитал
`kw_NN.json` → перевёл все статьи → записал ОДНИМ Write в `kw_tr_NN.json`
в ту же папку (`_extracted`) → следующий.

Не перечитывай записанное, самопроверок не делай. НЕ читай `cmn_tm.json`
и `LT00_RU.json` — они огромные.

## Что переводить

| Поле | Что это | Куда перевод |
|---|---|---|
| `term` | название термина | `term_ru` |
| `series` | серия-первоисточник | `series_ru` |
| `desc` | текст статьи | `desc_ru` |
| `desc2` | доп. текст (часто пустой — тогда оставить пустым) | `desc2_ru` |

Поля `idx`, `term`, `series`, `desc`, `desc2` копировать БЕЗ ИЗМЕНЕНИЙ.

## Формат

Переносы строк — настоящие `\n`, строка не длиннее 72 символов, разбиение
на абзацы как в оригинале. Если `desc2` пустая строка — `desc2_ru` тоже
пустая.

## Стиль

Энциклопедическая справка: ровно, без восклицаний, прошедшее время для
событий. Термин в заголовке — именительный падеж. Буква «ё».
UTF-8, русский НЕ в `\u`-эскейпах.
