# Правила перевода диалогов Super Robot Wars V (EN → RU)

Игра-кроссовер: «Космический линкор Ямато 2199», Гандамы (Z/ZZ/CCA/Юникорн/
SEED Destiny/00/Кроссбоун/Хэтэуэй), «Мазингер» (Shin Mazinger), «Евангелион»,
«Кросс Анж», «Стальная тревога!» (FMP), «Надэсико: Принц Тьмы», «Майтгайн»,
«Дайтарн 3», «Замбот 3», «Геттер Робо: Армагеддон». Оригинальные герои:
протагонист ($n) на машине «Вангрэй» (VangRay), ИИ-девушка Найн (Nine).

## Формат входного файла
{"blocks":[{"i":N,"speaker":"...","text":"...","orig":"..."}], "qstrings":[{"q":"...","ru":""}]?}

## Правила blocks
1. Поля "i" и "orig" копировать БЕЗ ИЗМЕНЕНИЙ. Переводить только "speaker" и "text".
2. "speaker" — строго по глоссарию `D:\games\SUPER ROBOT WARS V\_extracted\dialogs_en\_speakers_ru.json`
   (имена внутри текста — по нему же). Спикер "　" (U+3000) не менять.
3. Виды текста:
   - Реплика `「…」` — сохранить скобки; строки-продолжения начинаются с U+3000 `　`.
   - Мысли `（…）` — сохранить скобки; продолжения с U+3000.
   - Карточка локации: строки вида `　\n　　-Place Name-` — перевести имя места,
     сохранить структуру `-…-` и ведущие U+3000 (число можно менять для центровки,
     но строка не длиннее оригинала).
4. Число строк в "text" — как в оригинале или меньше; каждая строка НЕ ДЛИННЕЕ
   самой длинной строки оригинала этого блока (+2 символа максимум).
   Слова можно перераспределять между строками блока.
5. Плейсхолдеры сохранять: $n (имя героя — строить фразы нейтрально к полу),
   $kwb<термин>$kwe (перевести термин, маркеры оставить), $l $c $r $F.
6. Пунктуация в стиле оригинала: 「」『』（）…！？ Полноширинные символы не ломать.

## Правила qstrings (условия победы/поражения, варианты выбора)
Заполнить "ru" переводом "q" (само "q" не менять). Кратко, в стиле UI:
"Defeat all enemies." → "Уничтожить всех врагов.", "X is defeated." → "X уничтожен.".

## Стиль
Живая разговорная русская речь, буква «ё» обязательна. Военные — по уставу,
подростки — неформально. Злодеи — высокопарно, где это в оригинале.

## Вывод
Та же структура JSON, UTF-8, русский НЕ в \u-эскейпах. КАЖДЫЙ файл записывать
сразу после перевода (не копить). Большие файлы (>200 блоков) можно писать
двумя валидными JSON-половинами и склеивать python-скриптом.
