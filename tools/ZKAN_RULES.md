# Правила перевода статей энциклопедии SRW V (EN → RU)

## Порядок работы

Длинные ответы обрываются, поэтому строго по одному файлу за раз: прочитал
`zkan_rNN_route.json` → перевёл все статьи → записал ОДНИМ Write в
`zkan_tr_rNN_route.json` в ту же папку (`_extracted`) → следующий.

Не перечитывай записанное, самопроверок не делай. НЕ читай `cmn_tm.json`
и `LT00_RU.json` — они огромные.

## Что переводить

Заполнить поля с суффиксом `_ru`. Поля без суффикса скопировать БЕЗ
ИЗМЕНЕНИЙ, структуру JSON сохранить.

| Поле | Что это |
|---|---|
| `CHFN` | полное имя персонажа |
| `CHNN` | короткое имя |
| `PRDC` | серия-первоисточник |
| `ACTR` | актёр озвучки — транслитерация с японского |
| `DSCR` | описание |
| `DSC2` | текст «после прохождения»; если начинается с маркера `<srw-tag=before-clear-text-here>` — маркер сохранить ДОСЛОВНО в начале |

## Формат

Переносы строк в `DSCR`/`DSC2` — настоящие `\n`, строка не длиннее 72
символов, разбиение на абзацы как в оригинале. Стиль энциклопедический,
но живой. Буква «ё». UTF-8, русский НЕ в `\u`-эскейпах.
